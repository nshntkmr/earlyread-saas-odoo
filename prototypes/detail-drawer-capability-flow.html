Runtime Flow

1
Schema Builder
Admin registers a table or view from PostgreSQL, ClickHouse, Snowflake, or another supported connector.
2
Data Table
Widget SQL returns rows with a stable row key and any master-row fields needed in the drawer header.
3
Click Action
The configured column uses open_detail_drawer. Existing show_details and navigation actions stay separate.
4
Drawer Opens
Header and master-row sections render immediately from the clicked AG Grid row data.
5
Detail SQL
SQL sections call the detail endpoint with row_key. The executor uses the registered schema source.
6
Section Renderers
Field grids, chips, measure cards, alert blocks, badges, and dot strips render from config.
